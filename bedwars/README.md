# 床戰 BED WARS（網頁版）

Minecraft 床戰風格的 3D 第一人稱網頁遊戲。單人模式：4 隊 × 2 人，你和電腦隊友對抗 3 隊電腦。

## 怎麼玩
直接用瀏覽器打開 `index.html`，不用安裝。電腦和手機都能玩（手機請橫向）。

手機操作：左邊拖曳＝搖桿、右邊拖曳＝轉視角、⚔ 攻擊（按住挖方塊）、▣ 放置（按住連放）、跳、蹲（開關）、點快捷欄換物品、上方有商店／隊友／金蘋果／暫停按鈕。

| 按鍵 | 功能 |
|---|---|
| WASD | 移動（往前自動衝刺） |
| 滑鼠 | 看方向 |
| 空白鍵 | 跳 |
| Shift | 蹲下（不會掉下邊緣） |
| 基岩版搭橋 | 拿方塊對著前方空中按住放置往前走，方塊自動放在腳下前方，不用蹲 |
| 左鍵 | 攻擊／按住挖方塊 |
| 右鍵 | 放方塊／使用道具（按住連放） |
| 1–9／滾輪 | 切換物品 |
| E | 開商店（站在 NPC 旁） |
| G | 切換隊友指令（防守／跟隨／進攻） |
| Esc | 暫停 |

## 單機版／線上版
- **單機遊戲**：你和電腦隊友對抗 3 隊電腦。
- **線上遊戲**：按「建立房間」會得到房號，把房號或邀請連結傳給朋友，朋友按「加入」輸入房號。最多 8 人（4 隊 × 2），空位由電腦補上，點隊伍可以換隊，房主選電腦難度後開始。
  - 線上需要網路（使用 PeerJS 點對點連線，房主的電腦就是伺服器）。
  - 房主離開，房間就會關閉。

## 內容
- 資源生成器：鐵、金（基地）、鑽石（四角島）、綠寶石（中島）
- 道具商店（7 類）：
  - 方塊：羊毛、木板、終界石、防爆玻璃、黑曜石
  - 近戰：石劍、鐵劍、鑽石劍、擊退棒
  - 護甲：鎖鏈、鐵、鑽石
  - 工具：鎬子、斧頭、剪刀
  - 遠程：**魚竿**（勾住敵人或 TNT，再按一次拉過來）、弓、箭、雪球、火球
  - 道具：TNT、終界珍珠、搭橋蛋、救援平台、金蘋果
  - 藥水：速度、跳躍、隱身
- 團隊升級：鋒利劍、強化護甲、熔爐、治療池、入侵陷阱
- 電腦 AI：自動搭橋、防床、拆床、戰鬥；簡單／普通／困難
- 遊戲事件：鑽石 II／III、綠寶石 II／III、25 分鐘床自毀

材質：方塊、工具、角色都是程式產生的像素貼圖，方塊有環境光遮蔽陰影，手上的工具是立體像素模型。

使用 three.js r160。
