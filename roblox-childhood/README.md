# Roblox Childhood

23 個熱門 Roblox 遊戲的小遊戲合集，用 3D 方塊風格做成，照固定順序一關接一關玩。
（粉絲致敬作品，跟 Roblox 官方和各遊戲作者沒有關係，角色都是原創的。）

## 怎麼玩
- 直接用瀏覽器打開 `index.html` 就能玩，不用網路。
- 電腦：WASD 移動、空白鍵跳、滑鼠轉視角、左鍵動作、E 互動、P 暫停
- 手機：左邊搖桿移動、右邊拖曳轉視角，右下角有按鈕
- 失敗會在同一關重生；暫停選單可以調畫質（低畫質比較順）、重來或跳過這關
- 進度會自動存檔，主選單可以「繼續」，也可以重玩已經過的關卡

## 檔案
- `index.html`、`style.css`：頁面和介面
- `js/engine.js`：3D 引擎、操作、物理、介面
- `js/levels1.js` ～ `js/levels6.js`：23 個關卡
- `js/main.js`：選單和關卡流程
- `lib/three.min.js`：three.js r128（3D 繪圖函式庫）
