# 灰鷹軍團 GREY EAGLE

二次世界大戰風格的橫向推線對戰遊戲（單線出兵、打爆敵方碉堡）。
所有國家、陣營、人物都是虛構的，不使用任何真實政治符號。

## 怎麼玩
- 用瀏覽器打開 `index.html` 就能玩，不用網路，也不用安裝。
- 下方按鈕（或鍵盤 `1`～`0`）出擊角色；`Q` 後勤升級；`空白鍵` 發射要塞砲。
- 拖曳畫面或用 `←` `→` 左右看戰場，右上角可以切換 2 倍速，`Esc` 暫停。
- 進度自動存在瀏覽器裡；登入雲端帳號後會同步到雲端，換裝置也能接著玩。

## 內容
- **世界篇 40 關**：小國 → 遠方參戰國 → 四大強國，最後是紅星聯盟（鋼鐵巨熊＋冬將軍兩階段魔王）。
- **20 個國家**，每個國家的碉堡造型都不一樣（燈塔、風車、峽灣砲台、古神殿、木寨、城堡、紅星塔……），有些碉堡會開砲。
- **天氣**：淹水、下雪、濃霧。
- **三個章節**：通過第一章開放第二章、第三章（敵人更強）。
- **36 個我方角色、6 種稀有度**：
  - 基本（推關卡解鎖）、EX（達成條件取得）
  - 稀有、激稀有、超激稀有（常駐扭蛋）
  - 傳說稀有（傳說祭扭蛋，0.3%）
- Lv10 進化成第二形態；抽到重複角色會 +1 等級。
- 軍功用來升級角色和研究碉堡（耐久、要塞砲威力）。

## 雲端帳號
- 標題畫面的「☁️ 登入 / 註冊」。和「競技對決 ARENA」共用同一套帳號（同一個 Firebase 專案）。
- 存檔放在 Firestore `users/{uid}` 文件的 `ge`（存檔 JSON）和 `geUpd`（最後存檔時間）欄位，只用 updateMask 寫這兩個欄位。
  ARENA 那邊也改成只寫自己的欄位（name、prof、updated），兩個遊戲不會互相蓋掉。
- 不需要改 Firestore 規則（沿用「只能讀寫自己的 users/{uid}」）。
- 第一次登入：雲端沒有存檔就上傳這台裝置的進度，有的話改用雲端的。之後每次存檔 5 秒後自動上傳，打開遊戲時會抓別台裝置較新的進度。

## 檔案
- `index.html`、`style.css`：頁面和介面
- `js/data.js`：角色、敵人、國家、關卡、扭蛋資料（調數值改這裡）
- `js/battle.js`：戰鬥邏輯
- `js/draw.js`：所有圖像（全部用程式畫，沒有圖檔）
- `js/main.js`：選單、存檔、扭蛋、戰鬥畫面、音效
- `js/cloud.js`：雲端帳號和存檔同步

網址加上 `#debug` 會給一大堆勳章和軍功，方便測試。
