# 百門飯店 Hundred Doors

1～4 人連線的 Roblox 方塊風恐怖遊戲，總共 100 扇門。用 HTML + JavaScript + three.js 製作，不需要安裝任何東西。

## 怎麼玩
- 打開 `index.html` 就能玩單人。
- 連線需要網路，會用 PeerJS 點對點連線。一個人按「建立房間」，把 5 位代碼傳給朋友，朋友輸入代碼後按「加入房間」。
- 建議放到 itch.io 或 GitHub Pages 上，用網址玩，手機也可以玩。

## 操作
- 電腦：WASD 移動、滑鼠看、E 或左鍵互動、C 蹲下、F 開關燈、V 吃維他命、Esc 暫停。
- 手機：左下搖桿移動、右半邊滑動轉視角、右下按鈕互動、蹲、燈、維他命。

## 怪物（玩法參考 DOORS，角色是原創的）
| 怪物 | 怎麼活下來 |
|---|---|
| 狂嘯 | 燈閃爍、聽到轟隆聲 → 躲衣櫃 |
| 回馬槍 | 燈變綠 → 躲衣櫃，它會來回好幾次 |
| 暗嘶 | 黑暗房間聽到「噓」→ 轉頭看著它 |
| 千眼 | 紫光 → 不要看它 |
| 逆行者 | 藍色走廊，看到「轉身！」→ 往回走 |
| 追獵者 | 第 30～45 門追逐戰 → 一直跑 |
| 盲魔 | 第 50 門圖書館、第 100 門 → 蹲著走或躲衣櫃 |
| 假門 | 看清楚門牌號碼 |
| 抽屜蛛 | 開抽屜偶爾會被咬 |

## 檔案
- `js/world.js`：100 間房間的生成和 3D 模型
- `js/entities.js`：怪物模型和主機端 AI
- `js/game.js`：玩家、道具、UI、手機操控、遊戲流程
- `js/net.js`：連線（PeerJS）
- `js/audio.js`：合成音效
- 要改怪物名字：`js/entities.js` 最上面的 `NAMES`，以及 `index.html` 的怪物圖鑑
